# 7 Software Testing Principles

Software testing follows seven important principles that help testers perform testing effectively.

## 1. Testing Shows the Presence of Defects

Testing can show that defects exist, but it cannot prove that there are no defects.

## 2. Exhaustive Testing is Impossible

It is normally impossible to test every possible input and condition. Testers should prioritize important and high-risk areas.

## 3. Early Testing

Testing should start as early as possible in the software development life cycle.

## 4. Defect Clustering

A small number of modules usually contain most of the defects found during testing.

## 5. Pesticide Paradox

Repeating the same tests again and again may stop finding new defects. Tests should be reviewed and updated regularly.

## 6. Testing is Context Dependent

The appropriate testing approach depends on the type of software, project, risks, and business context.

## 7. Absence-of-Errors is a Fallacy

Finding and fixing many defects does not automatically mean that the software is useful or meets the users' needs.
