# V-Model in Software Testing

The V-Model, or Verification and Validation Model, is a software development model where testing activities are planned alongside development activities.

## Main Idea

Each development phase has a corresponding testing phase.

### Development Side

- Requirements Analysis
- System Design
- High-Level Design
- Low-Level Design
- Coding

### Testing Side

- Acceptance Testing
- System Testing
- Integration Testing
- Unit Testing

The two sides form a V shape.

## Advantages

- Testing is planned early.
- Requirements can be linked to testing activities.
- It provides a clear and structured process.
- Defects can be prevented or identified earlier.

## Disadvantages

- It is less flexible when requirements change frequently.
- Changes can be expensive after a phase is completed.
- It is more suitable for projects with relatively stable requirements.
