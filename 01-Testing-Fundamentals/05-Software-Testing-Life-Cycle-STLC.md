# Software Testing Life Cycle (STLC)

The Software Testing Life Cycle (STLC) is a sequence of activities performed by a testing team to ensure software quality.

## Main Phases

### 1. Requirement Analysis

The testing team studies the requirements and identifies what needs to be tested.

### 2. Test Planning

The team defines the testing strategy, scope, resources, schedule, tools, and responsibilities.

### 3. Test Case Development

Test scenarios, test cases, test data, and expected results are prepared.

### 4. Test Environment Setup

The required hardware, software, tools, databases, and configurations are prepared.

### 5. Test Execution

Test cases are executed and actual results are compared with expected results.

### 6. Defect Reporting

When the actual result does not match the expected result, a defect is reported and tracked.

### 7. Test Closure

Testing results are summarized, metrics are collected, lessons learned are documented, and the testing cycle is formally closed.

## STLC vs SDLC

STLC focuses specifically on testing activities, while SDLC covers the complete software development process.
