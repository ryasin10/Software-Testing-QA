# Software Testing Career Path

Software testing offers different career paths depending on experience, technical skills, and interests.

## Common Roles

### 1. Manual Tester / QA Tester
Focuses on manually executing test cases, finding defects, and verifying software behavior.

### 2. Automation Tester
Uses automation tools and programming to create and execute automated tests.

### 3. QA Engineer
Works on testing activities, quality processes, test planning, defect management, and improving software quality.

### 4. Senior QA Engineer
Handles more complex testing activities and may guide other testers.

### 5. QA Lead / Test Lead
Coordinates testing activities, manages the testing team, and helps plan testing strategies.

### 6. QA Manager
Responsible for broader quality assurance activities, teams, processes, and project-level quality.

## Important Skills

A tester should develop:

- Software testing fundamentals
- Test case design
- Bug reporting
- SQL and databases
- API testing
- Basic programming
- Automation testing
- Git and version control
- Agile/Scrum knowledge
- Communication and analytical skills
