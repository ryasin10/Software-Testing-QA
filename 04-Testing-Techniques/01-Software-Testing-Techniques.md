# 🧪 Software Testing Techniques

## Overview
**Software Testing Techniques** are standardized methods used to design better test cases. They help QA engineers maximize test coverage, save time, and systematically identify hidden bugs without exhaustively testing every single input combination.

---

## 🎯 Major Categories of Testing Techniques

| Category | Primary Focus | Examples |
| :--- | :--- | :--- |
| **Black Box Testing** | Verifies software behavior against requirements without looking at internal code. | Boundary Value Analysis, Equivalence Partitioning, Decision Tables |
| **White Box Testing** | Evaluates internal code structure, paths, and logic coverage. | Statement Coverage, Branch Coverage, Path Testing |
| **Experience-Based Testing** | Leverages tester intuition, domain knowledge, and past experience. | Exploratory Testing, Error Guessing |

---

## 💡 Why Use Test Design Techniques?
* **Reduces Execution Time:** Avoids redundant test cases by selecting representative inputs.
* **Maximizes Defect Detection:** Focuses on high-risk areas where defects typically concentrate.
* **Improves Test Coverage:** Ensures functional requirements and edge cases are thoroughly verified.
